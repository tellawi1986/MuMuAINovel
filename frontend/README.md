# MuMuAINovel Frontend

This is the React + TypeScript frontend for MuMuAINovel, an AI-assisted novel writing application.

## Stack

- React 18
- TypeScript
- Vite
- Ant Design
- React Router
- Zustand

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Notes

This frontend is the UI layer for the AI writing workflow, including project management, story planning, chapter editing, and analysis tools.
